# TITANS FC

Полноценный сайт футбольного клуба на React + TypeScript + Vite: главная, состав, тактика, информация о клубе и защищённая админка с CRUD.

## Запуск

```bash
npm install
npm run dev
```

Сайт: `http://localhost:5173`

Админка: `http://localhost:5173/admin`

Логин/пароль по умолчанию: **admin / titans2026**. Их можно переопределить через переменные окружения `VITE_ADMIN_LOGIN` и `VITE_ADMIN_PASSWORD` в файле `.env`.

## Хранилище данных

Проект использует встроенное постоянное хранилище на `localStorage` с полным набором CRUD-операций (`src/db.ts`). Это рабочая база данных без внешних зависимостей и ключей: данные сохраняются после перезагрузки и синхронизируются между вкладками браузера. Структура таблиц (`players`, `club`, `tactics`, `news`) совпадает с описанной в техническом задании.

Интерфейс и демо-контент переведены на русский и узбекский (переключатель RU / O'Z / EN в шапке и на странице входа). Язык запоминается; у каждого языка отдельная редактируемая база данных. По умолчанию — русский.

Данные можно выгрузить и загрузить обратно в разделе **Admin → Database**, а также сбросить к демо-набору.

Для подключения Supabase достаточно заменить реализации функций в `src/db.ts` на запросы к Supabase (таблицы и поля уже соответствуют схеме) — остальной код работает с абстракцией `database` и не меняется.

## Возможности

- Динамическая главная: статистика, состав, новости из базы данных.
- Состав: фильтры по позициям, поиск, профили игроков.
- Тактика: схемы 4-3-3, 4-4-2, 4-2-3-1, интерактивное поле, сохранение расстановки.
- Клуб: история, философия, цели, тренерский штаб, капитан — всё редактируется.
- Админка: защищённый вход, управление игроками, клубом, тактикой и новостями, импорт/экспорт базы.
- Адаптивная вёрстка для компьютеров, планшетов и телефонов.

## Тестирование

```bash
npm run build
npm run test
```

`npm run test` запускает smoke-тест в Chrome через Playwright (проверка загрузки страниц, авторизации, CRUD, сохранения после перезагрузки, перетаскивания игроков и адаптивности).
